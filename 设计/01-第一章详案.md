## 2. 情绪曲线与三段结构

```
情绪
 ↑  好奇              被推着跑              被接住
 │   ╱╲                ╱╲╱╲╱╲              ╱‾‾‾╲
 │  ╱  ╲______        ╱        ╲          ╱      ╲___
 └──────────────────────────────────────────────────→ 时间
   对话A   对话B    教学段  压力段  │ 高潮段   对话C   结算+知乎
   出租屋  门口     0-30s  30-105s │ 105-150s 展位前
```

- **教学段（0-30s）**：只放 1 张订单，不出现任何干扰。玩家在这里学会"一次只能拿一样""离开工位加工作废"。
- **压力段（30-105s）**：订单并发 + 投递口第一次关闭。玩家第一次体会"路线要重排"。
- **高潮段（105-150s）**：宣讲会倒计时，订单价值提升，时间告急。**这一段必须让玩家喊出"来不及了"**。

## 3. 关卡设计（第一章）

### 3.1 基础参数

| 参数 | 值 | 说明 |
|---|---|---|
| 时长 | 150 秒 | |
| 配额 | 8 份 | 达成即结束 |
| 加工耗时 | 1.1 秒 | 必须停在工位，离开则作废 |
| 玩家移速 | 96 px/s | |
| 队友移速 | 68 px/s | 慢，且会中途去接电话 |
| 交互半径 | 40 px | |
| 投递口关闭 | 每 42 秒关 6 秒 | 第一次在 t=42s |
| 障碍密度 | 0.18 | 对应布局生成器的 `obstacleDensity` |

### 3.2 工位与动线（双朝向）

**同一份逻辑描述，两种排布**（真实项目由布局生成器产出，原型阶段手写两份）：

| 朝向 | 画幅 | 工位排布 | 玩家动线 | 地图 |
|---|---|---|---|---|
| 横版 | 512×288（16×9） | 资料台(左上) → 工位(中上) → 投递口(右下) | "U" 字 | 20×12 瓦片 |
| 竖版 | 288×512（9×16） | 资料台(上) → 工位(中) → 投递口(下) | "丨" 字（含绕柱） | 12×20 瓦片 |

> 两种排布的**规则、分数、掉落、干扰事件时间线完全一致**，只有空间关系不同。这是"双端一等公民"能成立的关键。

### 3.3 干扰事件时间线

| 时间 | 事件 | 表现 | 玩家应对 |
|---|---|---|---|
| t=0s | 教学订单 ×1 | 只有 1 张小票 | 学会三段流程 |
| t=30s | 订单并发开启 | 小票队列变成 3-4 张 | 开始规划路线 |
| **t=42s** | **投递口暂停接收 6 秒** | 投递口变红 + 屏幕红闪 + 系统提示 | 先处理手上的活，别空跑 |
| t=75s | 人群涌入 | 背景群像变多，NPC 移速 -20% | 绕开人群 |
| **t=105s** | **宣讲会倒计时 + 心仪公司订单** | 金色小票出现，单价 ×2，限时 30 秒 | 优先级判断：保底还是搏一把 |
| t=135s | 最后冲刺 | 全场暖光加强 + 音乐加速 | 交完最后一单 |

## 4. 对话与插卡（双核互锁的核心）

三个节点，各 1 个抉择。**用卡不是选对，只是多一种解法**。

### 节点 A · 出租屋 · 凌晨两点

> 场景：手机屏幕是屋里唯一的光，投递记录停在"已投递 46 份，0 回复"。

**NPC 消息**

- 系统：「明天是春季招聘会，会后很多岗位会关闭。」
- 学长（微信）：「我明天也去，你要不要一起？不过我上午有个会，可能晚点到。」

**抉择：这 46 份没回音，明天怎么打？**

| 选项 | 代价 | 效果 |
|---|---|---|
| A1 「按匹配度排，只跑最对口的 3 家」 | 精力 -1 | 成长 +2；关卡：订单队列更集中，投递口关闭期间不刷单 |
| A2 「全都跑一遍，广撒网」 | 精力 -2 | 成长 +1；关卡：移速 -10%，但配额判定放宽到 7 份 |
| A3 「只去最想去的那家，其他随缘」 | 信任 ±0 | 成长 +1；关卡：t=105s 出现**心仪公司金色订单（单价 ×2）** |

- **卡槽**：接受【提问】【复盘】类型
- **插卡示例**：插入「带着笔记去汇报」→ 额外获得情报：**这次招聘会 3 家公司在招同一类岗位**（关卡内直接显示岗位匹配关系）

### 节点 B · 招聘会门口 · 学长

> 学长比主角高半个头，单肩包，手里两杯咖啡，姿态松弛。

**NPC 消息**

- 学长：「里面乱得很。你要挨个排，排到下午也投不完。」
- 学长：「我去年也是这么过来的——真的。」

**抉择：要不要花时间打听内幕？**

| 选项 | 代价 | 效果 |
|---|---|---|
| B1 「先花十分钟问清楚每家到底在招什么人」 | 时间 -10 分钟（叙事层） | 专业 +1、成长 +1；关卡：**显示岗位匹配关系**（哪份简章该投给哪家） |
| B2 「不问了，直接排队，先投出去再说」 | — | 团队 +0；关卡：**订单价值 +10%**，但会出现 2 张"投错的简历"需返工 |
| B3 「陪学长先去他公司那边看看」 | 精力 -1 | 信任 +1、团队 +2；关卡：**学长帮忙时间延长 30%**（他晚点再去开会） |

- **卡槽**：接受【提问】
- **开局卡的第一次教学机会**：插入「不懂就问」→ **解锁隐藏选项 B4**「问清楚目标、受众和交付形式，再决定跑哪几家」→ 专业 +2、成长 +2，并**把关卡内订单要求可视化**（小票上直接写出需要几份、限时多少）

### 节点 C · 心仪公司展位前 · 面试官

> 面试官抬起头笑了一下——**那个弧度和自己一模一样**（不解释，不给特写）。

**NPC 消息**

- 面试官：「你前面还有两位。……先说说，你为什么想来我们这？」
- 系统：「这是一个可以报 46 次拒绝的场合。」

**抉择：怎么答？**

| 选项 | 代价 | 效果 |
|---|---|---|
| C1 「讲我做过什么、能解决你们什么问题」 | — | 专业 +2 |
| C2 「讲我有多想来、有多努力」 | — | 信任 +1、成长 +0 |
| C3 「讲了实话：我投了 46 份，一封回音都没有」 | 精力 -1 | 信任 +2、成长 +2（**但风险：若前置选项里有 A2 广撒网，效果减半**） |

- **卡槽**：接受【举证】【共情】
- **插卡示例**：插入「带着笔记去汇报」→ C1 变 C1+（专业 +2 → +3，并解锁结算后的一句额外彩蛋）

### 4.1 双核互锁总表（本章必须让玩家感知到"因为我说了什么，所以关卡不一样"）

| 对话选择 | 改写的关卡参数 |
|---|---|
| A1 只跑 3 家 | 订单队列集中；投递口关闭期间不刷单 |
| A2 广撒网 | 移速 -10%；配额放宽到 7 |
| A3 只去心仪公司 | t=105s 刷出金色订单（×2） |
| B1 先问清楚 | 关卡内显示岗位匹配关系 |
| B2 直接排队 | 订单价值 +10%，但出现返工单 |
| B3 陪学长 | 队友有效工时 +30% |
| B4（插卡解锁） | 小票上直接写出需求与限时 |
| C3 说真话 | 结算文案分支；影响本章"狼狈卡"是否发放 |

**验收要求：以上至少 3 条要在首次游玩中被玩家实际看到。**

## 5. 分数、评级与掉落

```
分数 = 交付数 × 100 + 剩余秒数 × 3 + 最长连击 × 20 − 失误次数 × 40
```

| 评级 | 分数线 | 掉落 |
|---|---|---|
| S | ≥ 900 | 「带着笔记去汇报」+ 直接升「熟练」+ **隐藏卡「当场举手」** |
| A | ≥ 780 | 「带着笔记去汇报」+ 1 次升级机会 |
| B | ≥ 640 | 「先说我这边的时间」 |
| C | < 640 | 1 张「狼狈卡」（叙事收集品，不参与抉择） |

**第一章卡池（3 张）**

| 卡 | 类型 | 稀有度 | 效果 |
|---|---|---|---|
| 不懂就问（开局送） | 提问 | 普通 | 追问成具体目标/受众/交付形式，并把下一关订单要求可视化 |
| 带着笔记去汇报 | 举证 | 普通 | 「陈述」类选项带现场证据，专业翻倍 |
| 先说我这边的时间 | 拒绝 | 熟练 | 不损失团队评价地拒绝一次临时加派，附赠替代方案 |
| **当场举手**（隐藏，仅 S） | 提问 | 精通 | 在任何抉择中额外获得一条**只有主动开口才能拿到的情报** |

**结算页必须逐项显示分数构成**：交付 8×100、剩余 38 秒×3、最长连击 8×20、失误 1×−40。

## 6. 知乎内容位（核心必读 1 + 延伸 3）

**触发**：本局完成后自动检索。**失败也检索**，关键词换成失败原因。

| 位置 | 主题 | 优先类型 | 检索关键词 | 与机制的关系 |
|---|---|---|---|---|
| **核心必读** | 第一份工作怎么选 | **问答**（别人的同类经历） | `应届生 第一份工作 选择 纠结` | **读完解锁「带着笔记去汇报」的强化**（效果 +1） |
| 延伸 1 | 简历没有实习经历怎么写 | 文章 | `应届生 简历 没有实习经历 怎么写` | 收进观察笔记 |
| 延伸 2 | 招聘会怎么高效跑 | 问答 | `招聘会 怎么跑 高效 经验` | 收进观察笔记 |
| 延伸 3 | 面试被问到不会的问题 | 问答 | `面试 不会的问题 怎么回答 真诚` | 收进观察笔记 |

**失败分支关键词**：`求职 投了很多简历 没回音 心态`

**展示字段**（只取官方字段）：类型徽标 · 标题/问题 · 作者昵称 · 头像 · 一句话简介 · 认证 · 赞同·评论数 · 发布时间 · 话题标签 · 摘要/节选 · 「去知乎看原文」。

**入口**：关卡右下角常驻按钮 + 结算页固定区块；有内容时亮起小红点（数量 4）。**永不自动弹出。**

## 10. 第一章验收清单

- [ ] **陌生人能不看说明玩通**，且不卡在任何一步
- [ ] 至少 **3 条双核互锁**被玩家实际感知（"因为我问了 A，所以关卡里能看到 B"）
- [ ] 结算页能**逐项解释分数构成**，玩家知道自己差在哪
- [ ] 掉卡与评级一一对应，**重玩不掉卡**但刷新最高分
- [ ] 知乎入口：位置固定、不自动弹出、不遮挡操作；4 篇内容均可点开详情并跳转
- [ ] **全程零自动弹窗**（含结算、掉卡、知乎）
- [ ] 分享图能生成、能保存、文案与评级匹配
- [ ] **横竖两种朝向各通关一次**，且缩放均为整数倍
- [ ] 剪影测试：主角 + 学长 + 面试官 + 群像缩到 32×48 后仍能分辨
- [ ] 暗线只埋一处（面试官的笑容），**不做任何解释**
