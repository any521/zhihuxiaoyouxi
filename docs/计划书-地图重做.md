## 二、一个必须先说清楚的冲突

**第 6 条和第 3 条/开场插图是矛盾的，需要你拍板。**

上一版我把地毯做成墨绿 `#2f5d3a`，**理由是有据可查的**：
从开场插图「工位第一天」量化后的主色里量出来，那块绿占那张图的 **18.6%**。
也就是说 —— **剧情里的办公室就是绿地的**，我做地图时是照着它对齐的。

现在你要地面改成真实办公色（灰/米/木），那就会出现：

```
开场插图（工的位第一天）→ 墨绿地毯
地图（开放办公区）      → 浅灰地毯     ← 同一个地方，两个地面
```

**三个选择，你挑一个：**

| 方案 | 做法 | 代价 |
|---|---|---|
| **A（推荐）** | 地图改灰，**同时重生成那张开场插图**（把绿地毯改成浅灰）| 多生成 1 张插图 |
| B | 地图改灰，开场插图不动 | 一闪而过的镜头有色差，不细看看不出 |
| C | 地图开放办公区保留一块墨绿、其他区域改灰 | 不彻底，还是"绿地面" |

> 我建议 **A**：那张插图只出现 3.2 秒，重生成成本很低，但能保证"同一个地方"的连贯。
> 如果你选 B 我也能做，只是想先把话说在前面。

## 五、家具摆放规则（治"乱糟糟"）

### 5.1 分区归位：什么东西放哪个房间

| 家具 | 该在哪 | 现在的问题 |
|---|---|---|
| 打印机 / 复印机 / 碎纸机 | **文印区**（独立房间）| 挤在工位区角落 ✗ |
| 饮水机 | **茶水间**（不是走廊）| 现在工位区和茶水间各摆一个 ✗ |
| 文件柜 / 资料架 | **靠墙**（工位区北墙、储藏间）| 散在工位中间 ✗ |
| 绿植 | 走廊拐角、房间角落、窗边 | 现在工位区中间也摆了 ✗ |
| 垃圾桶 | 每个房间**入口内侧**各一个 | 现在乱放 ✗ |
| 沙发 | 接待区 / 总监办公室（访客用）| 现在工位区摆了个双人沙发 ✗ |
| 隔断屏风 | **只在工位群内部**，做十字分隔 | ✓ 基本对 |
| 讲台 / 投影仪 | **只在会议室** | ✓ |

### 5.2 摆放间距规则（上次踩过坑）

> 道具精灵是 **44~55 × 48**（约 1.5 格）。**不能按 1 格间距摆** ——
> 第一版就是这么错的：隔断 + 桌 + 键盘 + 椅子全糊在一起，看着像图坏了。

新规则写死：

```
· 同排（y 相同）的道具，x 至少隔 3 格
· 上下相邻（y 差 1）只允许"椅子塞进桌子下"这种**故意叠**
· 靠墙的道具，脚底贴到墙的那一格（y = 墙行 + 1）
· 桌面小件用 桌面:true 标记（不挡路、深度+0.5，否则会被桌子盖住）
```

### 5.3 工位群的标准单元

```
      ┌───┬───┬───┐        每个单元 3×3 格：
      │桌 │屏 │桌 │          桌(2,0) 屏(1,0) 桌(0,0)
      ├───┼───┼───┤          椅在 桌正下方一格
      │椅 │   │椅 │          桌面小件用 桌面:true
      ├───┼───┼───┤
      │桌 │屏 │桌 │        9 个工位 = 3×3 单元
      └───┴───┴───┘
```

### 6.3 规格

```
┌────────┬────────┐   四格是同一个人坐着的 4 帧打字循环：
│ 帧1    │ 帧2    │     帧1 双手放在键盘上（静止）
```

> ⚠️ 背影也不能省细节：**两个尖耳朵、白蛋形身体、椅背挡住下半身**。
> 坐着时看不到腿，所以**腿不用画**，这点要写进提示词，否则模型会画出悬空的腿。

## 七、NPC 专属对话与触发剧情

### 7.1 目标

现在点 NPC 只弹一张**人物卡**（职位/关系/印象），是**静态资料**。
你要的是**每个 NPC 有自己的对话和可触发的小剧情**。

### 7.2 设计

**每个 NPC 在每个"剧情段"有一套对话**，走到 TA 旁边按空格触发：

```
          段1(入职第1天)   段2(第3天)      段3(第二周)     段4(第二月)  …
林总      在开会，不理你    "进来。坐。"      "方案看了吗"      …
周岚      带你过流程        催初稿            边界感那件事       …
阿麦      带你下楼吃饭      聊饭馆            吐槽 deadline      …
韩策      "排期在第2页"     讲技术债          排期又改了         …
小鹿      "校园方向？"      问你要不要帮忙     茶水间那事         …
```

**规则**：
- 每个 NPC 每段 **3~6 条消息**的小对话，不改指标、不影响主线（和现有的"支线片段"同一套机制）
- 对话内容**跟着剧情走**：事件三之后，小鹿会提茶水间群；事件八之后，阿麦会提署名的事
- **有前提条件**：没认识的人不出现；还没发生的事不能提前说

### 7.3 数据量

5 个同事 × 大约 6 段 × 4 条 ≈ **120 条**。
这些是**文案**，我直接写进剧本文件，**不需要生成素材**。

### 7.4 交互方式

- 走到 NPC 旁 → 底部提示「**空格** 和周岚说话」
- 按空格 → 弹出**对话框**（地图上的对话，不是切到微信）
- 或者：切到微信，TA 给你发一条消息（更贴合"双模式"）

> 我建议**两种都用**：
> 简单寒暄 → 地图上的对话框（不打断走动）
> 有剧情推进的 → 切微信私聊
