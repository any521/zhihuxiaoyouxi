# 开场与 AVG 实现计划

> 目标：把游戏的**开头**做出来 —— 开场动画 + 剧情以「插图 + 卡片对话」的 AVG 形式展开。
> 素材已 45/45 齐备；音频暂缺，先留接口。

## 设计决定

### 界面形式：微信式（2026-09-13 改）

剧本本来就是私聊 + 群聊，所以 AVG **做成真正的微信界面**：
功能栏 58px + 会话列表 238px + 聊天窗口 flex（手机端列表/聊天二选一）。

两个直接好处：
- 玩家一眼就懂怎么操作（不用学新交互）
- **选项落在输入框的位置**，点选项 = 发消息，语义完全对得上

### 为什么 AVG 用 DOM 而不是 Phaser

沿用既有原则「**像素感来自画框，清晰度来自文字**」：
- **插图/头像/贴纸**：PNG 精灵 + `image-rendering: pixelated`
- **所有文字**：DOM 渲染。Phaser 在 512×288 上画中文必然糊

所以 AVG 是一层**盖在画布上的 DOM 层**（和现有 `StationLabels`、`StartOverlay` 同一套路）。

### 屏幕状态

现有 `phase` 只管关卡。新增一个正交的 `screen`：

```
screen: 'opening' | 'avg' | 'level'
   opening  开场动画（黑屏 → 镜头 → 标题卡），可跳过
   avg      插图 + 卡片对话，推进剧情
   level    现有 Phaser 办公室关卡（玩法小游戏）
```

## 里程碑

### M1 · 开场动画 ✅ 独立可跑
- 文件：`src/ui/Opening.tsx`
- 内容：黑屏 → 章节封面淡入 + 标题 → 三格镜头（出租屋 → 街上 → 写字楼门口）→ 标题卡「第一章 · 投出去的第 47 份简历」→ 自动进 AVG
- 验收：能看到完整动画；点任意处/按空格可跳过；双端都不溢出
- 截图：`tools/快照.mjs`

### M2 · AVG 引擎骨架 ✅ 独立可跑
- 文件：`src/ui/Avg.tsx` + `src/story/types.ts`
- 内容：插图底 + 左侧头像卡 + 底部卡片对话框 + 逐条播放（0.8~4 秒间隔）+ 点击加速/推进
- 验收：喂一段假脚本能逐条播完；文字不糊；双端排版正确

### M3 · 开场剧情（事件一前半）✅ 独立可跑
- 文件：`src/story/opening.ts`
- 内容：按剧本「事件一」——林总私聊 2 条 → 群聊邀请卡 → 群聊 8 条（小鹿/周岚/阿麦/韩策）→ 群里安静
- 验收：完整播完，说话人头像正确，贴纸正确插入

### M4 · 选项与三项指标
- 内容：A/B/C 三选一（卡片式按钮）→ 选定播放结果 → 三项指标（老板信任/团队协作/职业成长）变动
- 验收：三选一都能走通；指标面板数值正确；不可撤销

### M5 · 收束与进入关卡
- 内容：任务评价 → 两张知乎卡占位 → 无限追问占位 → 「继续实习生活……」→ 切到 `screen='level'`
- 验收：能一路走到办公室关卡，关卡能正常玩

### M6 · 双端与打磨
- 内容：移动端排版（竖版 288×512）、跳过/回看、音频接入点
- 验收：双端截图

## 约定（不许破坏）

- 🔒 **不改动**现有 Phaser 关卡的任何玩法逻辑；AVG 只是多一个 screen
- 🔒 **文字一律 DOM**，不许塞进 Phaser 画布
- 🔒 内部分辨率保持 **横 512×288 / 竖 288×512**，整数倍缩放
- 🔒 字号只用 **12 / 24 / 36** 三档（原生 12 的整数倍）
- 每完成一个里程碑：`npx tsc --noEmit` → `node tools/快照.mjs` → 看截图
