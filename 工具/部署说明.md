## 1. 为什么是这套做法（照抄「点废成金」）

宿主机原生 nginx 一个 `server` 块（80/443 各一个）服务所有子路径项目，
共享 location 都放在 `/etc/nginx/agrimind-common.conf`，各自的片段单独 include。

关键三条（都是从 dianfei 的配置里看出来的）：

1. **nginx 的 location 匹配的是百分号解码后的 URI** → 配置里**直接写中文原形** `location /刘看山/`，
   写 `%E5%88%98…` 反而匹配不上。
2. **磁盘目录镜像 URL 结构** → `root /srv/liukanshan;` + `/srv/liukanshan/刘看山/…`
   （`root` 模式下 `$uri` 自带前缀，index / SPA 回退天然自洽）。
3. **目录 URL 301 补尾斜杠** → 不补的话 `/刘看山` 会被兜底的 `location /` 接走，返回主站页面。

### ⚠️ 这台服务器的 SSH 会**偶发超时**

实测多次出现 `FATAL ERROR: Network error: Connection timed out` ——
**上传成功但紧接着的远程执行超时**（不是命令的问题）。所以：

- 部署脚本要**能重跑**（`部署-1` 是幂等的：解到临时目录再覆盖，跑几次结果一样）；
- 连着跑的命令要**配重试**：

```powershell
for ($i = 1; $i -le 4; $i++) {
  node 工具/远程.mjs sh "bash /tmp/lks-1.sh"
  if ($LASTEXITCODE -eq 0) { break }
  Start-Sleep -Seconds 3
}
```

- ⚠️ **判断"到底部署上没有"要看时间戳**：
  `ls -l /srv/liukanshan/刘看山/assets/index-*` —— 超时那次其实**什么都没做**，
  光看命令"跑过了"会误以为部署成功（我踩过一次）。

## 3. 踩过的坑（每一条都实测过）

| 坑 | 现象 | 处理 |
|---|---|---|
| **PowerShell → plink 的引号** | 远程命令里的引号被吃掉，`hostname` 直接没输出 | 用 `execFileSync` 传参数数组（`工具/远程.mjs`），**不过 shell** |
| **中文目录名** | Windows 传过去的可能是 GBK，落到服务器就变成另一个目录 | 一律 `printf '\xe5\x88\x98…'` **用 UTF-8 字节构造**，全程不传中文；用 `od -An -tx1` 目视核对 |
| **bash 不允许中文变量名** | `名=...` 被当成命令：`command not found` | 脚本里的变量名全用 ASCII |
| **Vite 默认 `base: '/' `** | 部署到子路径后 `/assets/x.js` 全部 404，页面 200 但白屏 | 改成 `base: './'`（dev 和线上都对，以后换目录也不用改）|
| **CSS 里写死的 `url('/assets/…')`** | 同上，而且**不会报错**，只是背景没了 | 图片移进 `src/assets/`，写成相对路径让 Vite 改写（打包后用 `Select-String "url\(/assets/"` 复查必须是 0 条）|
| **plink 拒绝未缓存的主机** | `Cannot confirm a host key in batch mode` | 用 `-hostkey` **钉住指纹**（比 `echo y` 盲目缓存更安全）：`SHA256:RNFvNPJOYhac8vcs9lBsEfcMAjNxi/zcw8xSfznnEdQ` |
| **`ERR_ABORTED` 不是失败** | 验收脚本会把音频池轮换时被 abort 的请求当成错误 | 验收脚本里显式放行 `ERR_ABORTED` |

## 5. 安全提醒（重要）

- ⚠️ **密码走的是明文（聊天里给的）** —— 建议尽快改密码，并改成**密钥登录**（把公钥放 `~/.ssh/authorized_keys`，然后关掉 `PasswordAuthentication`）。
  现在的 `工具/远程.mjs` 只从环境变量 `LKS_SSH_PW` 读密码，**仓库里没有密码**。
- ⚠️ 指纹 `SHA256:RNFv…nEdQ` 只能防"中途被换机器"，**证明不了这台就是你朋友的机器** ——
  要真正确认请用别的渠道核对一次。
- ⚠️ 我把 `agrimind-common.conf` 备份在同目录（`.bak-liukanshan-<时间戳>`）。要回滚：
  `cp -a <备份> /etc/nginx/agrimind-common.conf && nginx -t && systemctl reload nginx`。
