# 知乎小游戏 · 刘看山职场成长记

一个以知乎官方 IP **刘看山**为主角的小型独立游戏：从求职到成熟的职场成长故事，共 10 章。
玩法是 **《胡闹厨房》式的限时关卡** + **卡牌对话抉择**；每章通关后展示**知乎上真实对应的文章与问答**，可一键跳转详情。

> **接手开发请先读 [`设计/交接文档.md`](设计/交接文档.md)** —— 里面是全部既定规则、已完成的工作、以及必须遵守的约束。
> 🔒 标记的是已定稿的铁律（不要推翻），⚠️ 标记的是踩过的坑（别再走一遍）。

## 现在能玩到什么

第一章关卡 demo 已经跑通完整玩法链路：

```
简历架取空白简历 → 按订单要求过 排版台 / 打印机 / 盖章台（顺序随意）→ 投递箱交付
```

- **订单系统**（《胡闹厨房》式）：顶部挂 3 张随机订单，每张是「公司 + 需要的工序 + 分数」
- **不强制顺序**：想去哪台机器就去哪台；**多做了也算过**
- **地面物品**：`Q` 随时把手上的东西扔地上，靠近再按空格捡起来，**工序进度会保留**
- **限时**：180 秒内交付 8 单
- **双端**：PC 横版 512×288 / 手机竖版 288×512，都是整数倍缩放，像素完美

尚未实现：**卡牌对话剧情系统**、**知乎内容三步入口**、结算界面、分享图。

## 快速开始

```powershell
cd liukanshan-career
npm install
npx vite --host 127.0.0.1 --port 5273 --strictPort
# 打开 http://127.0.0.1:5273/
```

**操作**：`W A S D` 移动 · `空格` 取料/上机/交付/放下/捡起 · `Q` 随时丢下 · `Esc` 设置与暂停

**类型检查**：`npx tsc --noEmit`

## 素材流水线

132 个成品素材全部由 AI 生图 + 后处理得到。工具链（`工具/`，零依赖）：

```powershell
node 工具/检查素材.mjs                    # 清单校验：缺哪些 / 比例 / 命名 / 重复内容
node 工具/图片体检.mjs "<图片>"            # 色数 / 像素块游程 / 噪点
node 工具/转像素画.mjs "<原图>" "<成品>" --精确=512x288
node 工具/瓦片平铺测试.mjs "<材质图>"       # 3×3 看接缝
node 工具/剪影测试.mjs                     # 角色剪影可辨性验收
node 工具/处理素材.mjs                     # 一键后处理全部素材
node 工具/接入游戏.mjs                     # 拷进游戏工程（改成 ASCII 文件名）
```

**方法论要点**：AI 生图**不可能**直接产出真像素画（1024 图有 5 万~15 万色），
所以分两阶段验收 —— 原图只看**视角/构图/造型/道具齐备**，像素指标只在**后处理成品**上看。
详见 [`设计/交接文档.md`](设计/交接文档.md) §2.4。
