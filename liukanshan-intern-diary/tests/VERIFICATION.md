# 聊天界面改版验证记录（2026-09-12）

## 修改范围

仅修改本项目。SAVE_VERSION 保持 2，没有增加迁移、重置或新后端接口；评分和剧情内容不变。

- 两处首日继续按钮：继续实习生活……，18px、至少 44px；各状态显式深色文字。
- 统一头像映射、圆形抗锯齿遮罩、等比中心裁剪，群头像拼图及遮罩外未读点。
- 会话/联系人独立布局，单行省略摘要；本人头像位于气泡右侧。
- 300px 消息式邀请卡，入群后保留，重复点击打开群聊而不重复加群/通知。
- 功能栏横竖分隔线；网页缺字图标改用项目内生成的通用 SVG 线性图标。

## 验证方式与结果

使用本机现有 Godot 4.4.1 Stable Compatibility 运行和导出；没有修改项目声明的版本，也没有声称在 4.7 上验证。

1. `scripts/main.gd --check-only`：通过，无解析错误。
2. `--script res://tests/ui_regression.gd`：实际创建 1280×720 渲染窗口，结果 `UI_REGRESSION_RESULT: PASS`。
3. 回归脚本通过鼠标输入事件点击按钮，验证首次邀请、逐条消息、重复入群、介绍、撤回、周岚解锁、私聊追问、两处继续按钮推进、后续阿麦解锁与加载。
4. 横图 256×128、竖图 128×256 的红色正圆测试图：渲染后像素检查横纵直径差不超过 1px，确认 cover 不拉伸。
5. 普通/悬停/按下/禁用的样式对照和实际焦点/禁用截图已检查。深色 #202020 对 #E5E5E5 对比约 12.9:1。
6. 原生测试使用 `isolated_main.gd` 的内存存档，不读取或写入真实玩家存档。真实存档测试前后 SHA-256 均为 `534718DFF09223B48D0697371F28AC37A9DC38812B11450983098779FF21843B`。
7. 已重新导出 `public/game/`。最终导出日志无错误，测试目录不打入网页包。
8. 浏览器使用独立源 `http://127.0.0.1:3901/game/`，实际点击完成入群、自我介绍、群消息、周岚私聊、追问降级、返回林总、再次打开邀请和继续到第三天。更新网页包后刷新，测试进度仍保留。

## 2026-09-12 后续流程修正

- 明确启用高 DPI，并继续使用 MSDF 中文字体；清晰度仍会受到浏览器非 100% 缩放和系统截图压缩影响。
- 群内追问完成布局并滚动到可见位置后保留 1.1 秒，再被周岚撤回；测试同时验证显示前态和撤回后态。
- 每次普通任务选择后停留在当天，显示两个知乎高赞回答占位卡以及手动进入下一任务按钮。
- 过渡改成 0.9 秒像素沙漏时间页 + 0.75 秒日期页，实测总时长不少于 1.5 秒。
- 程女士和阿麦的跨联系人台词使用显式会话字段，回归验证不会进入林总聊天。
- NPC 追问取消 3 次上限；回归验证已追问 3 次后输入框与按钮仍可用。

## 入口与限制

本次启动的本地静态试玩入口为 `http://127.0.0.1:3800/game/`，由本项目 public 目录提供；不访问原 3800 存档进行测试。3901 是独立浏览器测试存档，不是玩家原进度。

静态试玩没有运行 Node/Vercel API，因此网页追问验证的是已有预写降级回复，不代表实时模型 API 通过测试。线上部署、知乎 OAuth 和其他未修改玩法不在此次验证范围。

复跑：在项目目录运行 Godot 可执行文件，参数 `--path . --script res://tests/ui_regression.gd`。测试截图写入 tests/screenshots，测试用例只使用内存存档。
