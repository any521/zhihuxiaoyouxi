### §0-F 规格速查（生成比例 → 成品尺寸）

**生成比例是你生图时在工具里选的，成品尺寸是入库像素——两者不是一回事。**

**只用这五种比例**：`1:1` `4:3` `3:4` `16:9` `9:16`。
**不要用 4:1 / 3:1 这类长条**——多数工具不支持，而且宽条会把每帧压得很小、更容易风格漂移。
**多帧一律用 1:1 + 网格**：1024×1024 里 2×2 网格每格是 512×512，比长条里的 256×256 清楚一倍。

| 资产 | 生成比例 | 生成尺寸 | 网格排布 | 成品尺寸 |
|---|---|---|---|---|
| 风格基准图 | 1:1 | 1024×1024 | 单图 | 1024×1024（只作参考） |
| 角色总表（三视图+表情+动作） | 1:1 | 1024×1024 | 4×4 | 32×48 精灵 |
| 角色行走 4 帧 | 1:1 | 1024×1024 | **2×2** | 128×48 精灵表 |
| 角色动作 6 帧 | 1:1 | 1024×1024 | **3×2** | 192×48 精灵表 |
| 角色头像 4 表情 | 1:1 | 1024×1024 | **2×2** | 96×96 ×4 |
| 全家福 6 人 | **16:9** | 1920×1080 | 单排 | 1920×1080（展示） |
| **背景横版** | **16:9** | 1920×1080 | 单图 | **512×288** |
| **背景竖版** | **9:16** | 1080×1920 | 单图 | **288×512** |
| 章节封面 横/竖 | 16:9 / 9:16 | 1600×900 / 900×1600 | 单图 | 512×288 / 288×512 |
| 瓦片材质 4 张 | 1:1 | 1024×1024 | **2×2** | 32×32 变体 |
| 道具 7 件 | 1:1 | 1024×1024 | **3×3** | 单件 ≤64×64 |
| 家具 3 件 | 1:1 | 1024×1024 | **2×2** | 单件 ≤96×128 |
| UI 卡牌框 | **3:4** | 1024×1365 | 单图 | 96×128（九宫格） |

## §11 验收总表（每批出完先过这张表）

| 检查项 | 通过标准 |
|---|---|
| 尺寸 | 落在 32×32 网格倍数上，无半像素 |
| 用色 | 不超过 16 色，全部来自 art-bible §4 调色板（容差 ≤2 色） |
| 描边 | `#241a12` 或同色系深色，**不是纯黑** |
| 光影 | 底部 1 像素暗边 + 椭圆投影；左上 1 像素亮边；**全场光源方向一致（左上 45°）** |
| 抠图 | 品红底无残留；边缘为硬边（无羽化） |
| 文字 | **零文字、零编号、零网格线、零水印** |
| 品牌锚 | 每张场景图至少出现一次知乎蓝 `#4a8fd4` |
| 角色一致性 | 与 `角色_全家福6人.png` 并排，剪影/主色/道具三项可辨 |
| 场景呼应 | 招聘会系列偏冷（`#cfe3ff`），办公系列偏暖（`#ffd9a0`），**不能混** |
| 提示词 | 12 字段写满；风格前缀未经手改；垫图与 seed 符合 §0-E |

### 最常被退回的五种情况

| 症状 | 处置 |
|---|---|
| 风格漂移（这一批和上一批不像） | **整批重出**，同 seed 同会话，不要单张修 |
| 场景空旷没人味 | 回看字段 5，**必须列出 3-5 件生活化小物** |
| 白狐边缘被吃掉 | 检查是否用了白底/绿底，**统一改品红底** |
| 六个角色认不出谁是谁 | 改**剪影**（身高/耳朵/尾巴/姿态），不要加颜色 |
| UI 像现代扁平/玻璃拟态 | 强调"磨砂塑料 + 1px 亮边 + 深棕描边 + 无渐变高光" |
