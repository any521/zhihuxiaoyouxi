## 二、通用注意事项（每张都要对照）

### 2.1 主角的画法（**错了整张重来**）

所有角色都是**拟人化北极狐**，画法必须一致：

```
· 整个身体是一块上窄下宽的圆润白色蛋形（臀部比肩部宽）
· 没有脖子、没有肩线，头和身体不分家
· 头顶两个白色尖三角耳朵（约体高的五分之一）
· 脸的上部有一个很大的黑色圆鼻子
  （宽度约为体宽的三分之一到五分之二，接近圆形，非常显眼）
· 鼻子的两侧各有一个很小的黑色圆点眼睛，和鼻子在同一水平线
· 没有嘴、没有胡须、没有眉毛
· 两只手臂与两条腿都是黑色
```

> 最容易错的是**鼻子**：很多模型会画成"小三角鼻子 + 一张嘴"的普通狐狸。
> 必须是**一大块黑色圆鼻子、没有嘴**。

### 2.2 每个角色的区别（靠衣服，不靠毛色）

## 三、第 1 批 · 坐姿动画（7 套，最关键）

### 3.1 为什么要这样做

现在同事用的是**站立朝向帧**，只能让他们"站在工位旁边"，非常假。
坐姿单独做一套，**坐到椅子上打字**。

### 3.2 四格怎么排

```
┌──────────┬──────────┐   四格是**同一个角色坐着的 4 帧打字循环**：
│  帧 1    │  帧 2    │
│ 双手在键 │ 左手抬起 │     帧 1 → 帧 2 → 帧 3 → 帧 4 → 回到帧 1
├──────────┼──────────┤     循环播放，看起来像在敲键盘
│  帧 3    │  帧 4    │
│ 双手在键 │ 右手抬起 │   四格大小一致、角色各自居中
└──────────┴──────────┘
```

### 3.3 三条必须写进提示词的约束（不写就会画错）

1. **只画到腰部以上** —— 坐着时下半身被桌子和椅子挡住，
   画了腿会悬空穿帮。**腰部以下留空（透明/品红）**。
2. **视角是"纯背面俯视"** —— 角色**完全背对镜头**坐着。
   画面里只有后脑勺、两个竖起的尖耳朵、后背和肩膀，
   **绝对看不到脸**（没有鼻子、没有眼睛、没有嘴、也没有侧脸轮廓）。
   谁是谁靠**衣服颜色**区分（见 2.2 的角色表），不靠脸。
3. **不画椅子、不画桌子** —— 椅子是地图上的独立道具，会画在同一个位置，
   画面里再画一次会叠成两层。
