# 提示词 06 · 界面背景（2 张）

> 存到 `美术/素材库/原图/15-界面背景/`
> **全部垫 `参考_风格基准图.png`，权重 0.45**
> 全部 **1:1 · 1024×1024**

## 配色方向（2026-09-13 改）

**米白为主 + 绿色点缀**，不用深色。
米白取 32 色板里的 `#f7efdd`，绿色取 `#a8d98a / #7cc26b / #4a8f4f`——
都是项目既有的色板色，和角色、道具、气泡能接得上。

这样一来整个界面变成**浅色主题**（和微信真实观感一致）：
- **聊天区**：米白底 + 淡绿暗纹
- **左侧侧栏**：深绿底（这就是"适当的绿色"）
- 我方气泡本来就是 `#a8d98a` 绿、对方气泡是米白 —— **现有素材原样能用，不用重做**

## 用途与约束

这两张是**聊天软件底纹**，文字和气泡会压在它上面，所以：

| 要求 | 写进提示词的说法 |
|---|---|
| **米白为主** | 点明"米白，占八成五以上"，给出色值 |
| **绿色点缀** | 图案用浅绿，少量、疏落 |
| **不能抢前景** | 图案只比底色深一点点，对比度极低 |
| **不能机械** | "疏密随机、有大有小、不要等距网格" |
| **要能平铺** | "四边可以无缝拼接，图案到边自然延续" |
| **要认得出主题** | 明确列出刘看山剪影 / 赞同箭头 / 气泡 / 问号 |

## B01 · 聊天区底纹（米白 + 淡绿）

`1:1 · 1024×1024 · 垫参考_风格基准图.png 0.45 · 底纹_聊天区_米白.png`

```
温暖手绘感的 16-bit 像素画，清晰的方块像素与锐利的像素边缘，纯粹的像素画风格。
cozy hand-painted 16-bit pixel art, crisp square pixels, pure 2D pixel art.

内容：一张聊天软件用的**重复底纹**，整张画布被同一种淡纹铺满。
底色是**温暖的米白色**（#f7efdd）——像旧纸、像奶油，干净、明亮、温暖，绝不是纯白、绝不是灰色。

底纹由下面五种小图案组成，它们**疏密随机地散布**，不是等距网格：
一、白色北极狐的头像剪影：两个尖耳朵、圆脑袋、脸中央一个黑色的大圆鼻子（用浅绿画）
二、一个向上的赞同箭头（用浅绿画）
三、一个圆角的聊天气泡（用米色画）
四、一个问号（用米色画）
五、几颗很小的星星与圆点（用浅绿画）

这五种图案的**大小不等**（大约 32 到 72 像素）、**间距不等**（有的挨得近、有的离得远），
排列要显得自然、随机，绝不能排成规整的横竖网格。

**所有图案的对比度都极低**：图案只比底色深一点点，绝不抢眼。
用 #a8d98a（浅绿，数量最多）、#d8e4c0（更淡的绿）、#e8dcc0（米色暗一档）三种颜色画。
远看就是一层很淡的、带点绿的暗纹。

视角与构图：正视，满铺整张画布。

光线：光照绝对均匀，没有明暗渐变、没有中心亮四周暗、没有阴影、没有暗角。

配色：只使用 #f7efdd #e8dcc0 #d8e4c0 #a8d98a 四种颜色，
其中 #f7efdd 占整张图面积的八成五以上。

背景：无背景（整张画布就是底纹本身）。

【画面约束】这是纯底纹，画面里没有任何人物、没有任何完整的插画、没有文字；
底色必须是**米白**，不许是纯白、不许是灰、不许是深色、不许有渐变；
图案的颜色必须以**浅绿**为主，米色为辅，绿的比例要明显多于米色；
图案必须**疏密随机、大小不等**，绝对不许排成规整的等距网格；
图案对比度必须极低，远看是一层很淡的暗纹；
四条边都可以和自身的副本无缝拼接：图案到边自然延续，边缘处不出现边框或分界线；
画面中不出现任何文字、字母、数字、水印、签名。
排错检查：如果底色看起来是纯白、灰色或深色而不是温暖的米白，这张图就是错的。
排错检查：如果画面里几乎没有绿色、全是米色或灰色，这张图就是错的。
排错检查：如果图案排成了规整的横竖网格、间距完全一致，这张图就是错的。
排错检查：如果图案比底色深很多、很抢眼，这张图就是错的——它必须非常淡。
排错检查：如果画面里出现任何文字或数字，这张图就是错的。
```
